# Changelog

## 0.0.2 — Snow Leopard

Stabilization only: correctness, performance, reliability and simplification, with no new language or query features.

- Keep sibling workspaces responsive during indexing cancellation and registration adoption; version durable registry setup without discarding existing settings.
- Use compact, bounded query coordination status and reserve pagination metadata headroom. Preserve frozen findings, source, coverage and snapshot evidence as live status changes.
- Reduce repeated SQLite statement/classification/source-offset work and retain relevant compilation coverage. Bound compiler JSON-RPC buffering and experimental Rust navigation concurrency/cache residency.
- Preserve linked-source origin evidence, report unresolved-name gaps, correct C# generated-file/diagnostic classification, and retain primary-constructor base/argument calls. Reject lossy .NET path and raw-query encoding before native use.
- Verify complete package-tool cache contents, validate Darwin socket peer ownership, and secure only the owned DATA leaf's permissions/ACL while protecting actual/configured home directories and retained data.
- Tighten CLI/MCP argument validation and structured-error exit behavior; add help without account initialization and named quick/core/extended validation tiers.

Update the runtime and managed/JavaScript/native SDK components together. The compact query shape uses native query contract9 and cursor control3; incompatible SDK/native pairs return `update_required`, and old cursor formats require restarting pagination. Worker protocol7 and store format8 remain unchanged. Existing package-tool caches using the old entry-only format require reacquisition before offline use.

Supported distribution remains macOS 15+ Apple Silicon, with separately installed Node24 and .NET10 SDK. TypeScript/C# are supported; Swift/Rust remain experimental. Published builds retain zero usage telemetry. Cross-repository queries, Angular template references and refactoring continuity move to later releases with timing undecided.

The [review ledger](docs/CODEBASE_REVIEW_0_0_2.md) and [release plan](docs/RELEASE_PLAN.md) record stabilization evidence, residual limits and artifact-bound distribution checks. Real video-encoding responsiveness remains unmeasured; no contention-performance certification is claimed.
