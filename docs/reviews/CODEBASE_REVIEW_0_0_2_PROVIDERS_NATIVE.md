## Architecture decisions

- **6, legacy native entry points:** retained. Removing existing public APIs needs a product/API decision; it is not necessary for these fixes. The current reserved path and legacy wrappers retain their existing admission/cancellation contracts.
- **11, provider duplication:** concrete sharing only: `providers/shared/source.mjs` now owns normalized relative paths and the exact UTF-16→UTF-8 map used by TS/Rust; Swift uses the same relative-path helper. The shared JSON-RPC fix serves both Rust and SwiftPM. No batching/diagnostic framework or second engine was introduced.
- Host dependencies, capability/schema consolidation and core/runtime/storage edits belong to their other lanes. Experimental Rust/Swift changes above are stabilization of existing adapters, not new language acceptance.
